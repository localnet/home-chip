# HomeChip

A local-first smart home hub built exclusively on the [Matter](https://buildwithmatter.com) protocol.

HomeChip runs entirely on your local network — no cloud, no subscriptions, no vendor lock-in. It exposes a [JSON-RPC 2.0](https://www.jsonrpc.org/specification) WebSocket API that any client can connect to: web apps, mobile apps, or custom integrations.

> **Status:** Early development. Not yet ready for production use.
